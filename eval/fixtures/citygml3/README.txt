Synthetic CityGML 3.0 fixtures for the pykci 3.0 codec (ingest_citygml.py / export_citygml.py).
All three files are XSD-valid CityGML 3.0 (validate_citygml.py --version 3: VALID, 0 duplicate ids,
0 unresolved local refs; xmllint with the offline catalog agrees). Generated by
a script; the counts below were computed from the files with lxml, not by hand.
CRS: srsName urn:adv:crs:ETRS89_UTM32*DE_DHHN2016_NH only on the CityModel gml:boundedBy Envelope
(srsDimension 3); no srsName on any geometry (like the reconstruction tiles).

tile_a.gml / tile_b.gml  two 1 km "street-space tiles" mimicking the reconstruction writer:
  tran:Road "road_shared" -> tran:section/Section "sec_shared" -> TrafficSpace "ts_group_shared" in BOTH
  tiles with identical space attributes (class B, function 1, usage 2+3, granularity way, gen attr 'group')
  but DIFFERENT TrafficAreas (tile_a: ta_a_1, ta_a_2; tile_b: ta_b_1, ta_b_2) and a different, tile-clipped
  lod0MultiCurve per tile (so a merged space carries 2 lod0 curves). Per-tile extra spaces:
  tile_a ts_a_2, ats_a_2 (in the Section), ats_a_1 (on the Road), Intersection isec_a (2 lane spaces with
  predecessor -> #ts_group_shared, 2 Markings); tile_b ts_b_2 (predecessor tile_a.gml#ts_a_2, successor
  tile_a.gml#ts_isec_a1 = cross-document refs), one TrafficSpace with NO gml:id whose TrafficArea,
  MultiSurface and Polygon also have no gml:id, ats_b_1. Road attributes are identical except: tile_b
  adds gml:name and gen attr 'tile_b_only', tile_a has gen attr 'tile_a_only' (robustness test for
  accumulating _gen_attrs_map; the real writer keeps space attributes identical). tile_a also: tran:Track
  with Section; CityFurniture lamp template "tpl_lamp" inline + xlink (identical id and geometry in tile_b),
  a 'regulates' relation from frn_a_2 to a lane space, fence (lod2MultiSurface), bollard (lod1Solid),
  SolitaryVegetationObject (inline template tpl_tree), PlantCover (lod0MultiSurface XLINK to ms_ata_a_1,
  lod2Solid, averageHeight, relation 'equal'), Bridge (relation 'carries' -> ta_a_1) +
  BridgeConstructiveElement, OtherConstruction (lod0MultiSurface/lod1Solid/lod2MultiSurface, con:height,
  externalReference), WaterBody/WaterSurface, LandUse, GenericLogicalSpace (lod0MultiCurve +
  GenericAttributeSet). tile_b: Bridge with a cross-document 'carries' relation to tile_a.gml#ta_a_1.
  Both: Building "bldg_shared" byte-identical in both tiles; ONE CityModel-level Appearance whose
  X3DMaterials target polygon ids including template polygons (tpl_lamp_f_*, tpl_tree_f_bottom).
