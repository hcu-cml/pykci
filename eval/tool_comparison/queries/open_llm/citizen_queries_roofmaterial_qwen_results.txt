// 2. What is Hamburg's most common roof material?
//    Shows the distribution of predicted roof materials across all buildings,
//    with percentage share.
// -----------------------------------------------------------------------------

```cypher
MATCH (b:Building)
WHERE b.predictedroofmaterial IS NOT NULL
WITH b.predictedroofmaterial AS material, count(b) AS count
WITH collect({material: material, count: count}) AS materials, sum(count) AS total
UNWIND materials AS m
RETURN m.material AS material, m.count AS count, round(m.count * 100.0 / total, 1) AS percentage
ORDER BY m.count DESC
```

Hamburg's most common roof material is **roof_tiles**, with a 55.8% share.

The distribution of predicted roof materials across all buildings is as follows:
*   **roof_tiles**: 55.8%
*   **tar_paper**: 26.4%
*   **concrete**: 11.8%
*   **metal**: 4.4%
*   **glass**: 1.7%

// 4. Which roof shapes are most popular in Hamburg?
//    Flat, Gable, Hip, Mono-Pitch — shows the architectural character
//    of different neighbourhoods.
// -----------------------------------------------------------------------------

```cypher
MATCH (b:Building)-[:HAS_ROOF_TYPE]->(rt:RoofType)
WHERE b.gemeindeschluessel STARTS WITH '02'

ORDER BY building_count DESC
```

Based on the query results, the **Flat Roof** is the most popular with 169,964 buildings, followed closely by the **Gable Roof** with 162,368 buildings. The **Hip Roof** (29,990) and **Mono-Pitch Roof** (21,202) are less common.
