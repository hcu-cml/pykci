
Hamburg has **388,267 buildings** in the dataset. On average, the buildings are **7.7 meters tall** and have **1.7 storeys above ground**.

// 2. What is Hamburg's most common roof material?
//    Shows the distribution of predicted roof materials across all buildings,
//    with percentage share.
// -----------------------------------------------------------------------------

What is Hamburg's most common roof material? Shows the distribution of predicted roof materials across all buildings, with percentage share.

```cypher
MATCH (b:Building)
WHERE b.predictedroofmaterial IS NOT NULL
WITH collect(b.predictedroofmaterial) AS materials
UNWIND materials AS material
WITH material, count(*) AS count
WITH sum(count) AS total, collect({material: material, count: count}) AS data
UNWIND data AS d
RETURN d.material AS roof_material, d.count AS count, round(toFloat(d.count) / total * 100) AS percentage
ORDER BY d.count DESC
```

Hamburg's most common roof material is **roof_tiles**, which accounts for **56.0%** of all buildings.

Here is the full distribution of predicted roof materials:
- **roof_tiles**: 56.0% (108,659 buildings)
- **tar_paper**: 26.0% (51,435 buildings)
- **concrete**: 12.0% (22,923 buildings)
- **metal**: 4.0% (8,550 buildings)
- **glass**: 2.0% (3,232 buildings)
